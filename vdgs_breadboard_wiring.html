Arduino Uno R3 — Breadboard Wiring Diagram

Click any component below to highlight only its wires so you can wire step-by-step without mistakes.

1. Power Rails
Arduino 5V → Breadboard + rail
Arduino GND → Breadboard - rail
2. HC-SR04 Ultrasonic
VCC → 5V | GND → GND
TRIG → D9 | ECHO → D10
3. Three LEDs (330 Ω each)
Green: D5 → 330Ω → + | - → GND
Yellow: D6 → 330Ω → + | Red: D7 → 330Ω → +
4. Active Buzzer
+ (long leg) → D8 | - → GND
5. 0.96" I2C OLED
VCC → 5V | GND → GND
SDA → A4 | SCL → A5
6. Push Button (Optional)
Leg 1 → D2 | Leg 2 → GND
